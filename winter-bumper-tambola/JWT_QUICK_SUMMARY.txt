🔐 JWT AUTHENTICATION - QUICK SUMMARY
=====================================

WHAT'S ADDED:
✅ Backend JWT endpoints (/api/auth/login, /auth/refresh, /auth/logout, /auth/me)
✅ Frontend login page with JWT integration
✅ Automatic token refresh before expiry
✅ Protected routes that require authentication
✅ Token storage in localStorage
✅ Axios interceptor for automatic token injection

REQUIRED SECRETS (Generate with: openssl rand -base64 32):
1. JWT_SECRET (32+ chars)
2. JWT_REFRESH_SECRET (32+ chars, different from JWT_SECRET)

ENVIRONMENT VARIABLES TO SET:
Backend (Render):
  - NODE_ENV=production
  - PORT=10000
  - MONGODB_URI=<your-mongodb-atlas-uri>
  - JWT_SECRET=<32-char-random>
  - JWT_REFRESH_SECRET=<32-char-random>
  - JWT_EXPIRES_IN=7d
  - JWT_REFRESH_EXPIRES_IN=30d
  - CLIENT_URL=https://winter-bumper.vercel.app
  - RATE_LIMIT_WINDOW_MS=900000
  - RATE_LIMIT_MAX=100

Frontend (Vercel):
  - VITE_API_URL=https://winter-bumper-backend.onrender.com

FILES ADDED:
Backend:
  - backend/src/utils/jwt.js (JWT utilities)
  - backend/src/middleware/auth.js (Auth middleware)
  - backend/src/controllers/authController.js (Auth endpoints)
  - backend/src/routes/authRoutes.js (Auth routes)

Frontend:
  - frontend/src/services/auth.js (Auth API + interceptor)
  - frontend/src/hooks/useAuth.js (useAuth hook)
  - frontend/src/store/authStore.js (Zustand auth store)
  - frontend/src/components/layout/ProtectedRoute.jsx (Protected route wrapper)
  - frontend/src/pages/LoginPage.jsx (Login UI)

HOW TO USE:
1. Generate JWT secrets: openssl rand -base64 32 (run twice)
2. Update backend/.env with secrets
3. Update frontend/.env with backend URL
4. Deploy to Render (backend) + Vercel (frontend)
5. Set environment variables in Render + Vercel dashboards
6. Test login at https://winter-bumper.vercel.app/login

TOKEN FLOW:
User → Login → Get accessToken + refreshToken
     → Save in localStorage
     → Use accessToken in API requests
     → When expires → auto-refresh with refreshToken
     → Continue playing!

SECURITY:
✅ Tokens signed with secret (can't be forged)
✅ Tokens expire (7 days for access, 30 days for refresh)
✅ Tokens verified on every request
✅ Automatic token refresh prevents interruption
✅ localStorage used (not vulnerable to CSRF)
✅ HTTPS required in production
